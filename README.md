# Robit

A make.fun entry for **One Word From Grandma**: the single word a grandma would text about AI.

## The word

**robit** — grandma's typo for "robot". She means the robot, she types it the way it sounds to her, and she sends it before anyone can correct her. Warm, a little baffled, funny in one word, and unmistakably about machines.

Why it fits the judge's criteria: it reads as one texted word, not a sentence; it sounds like a real grandmother typing to a grandchild; the joke lands with no caption; it is tied to robots and AI; and it is a fresh pick that is still instantly readable — the typo she would actually make.

## Run

```sh
node main.ts
```

Writes exactly `robit` (5 bytes, no trailing newline) to `/output/entry.txt`. Set `OUTPUT_PATH` to write elsewhere for local checks.
